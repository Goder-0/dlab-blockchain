# Vote Story Lesson

학생 실습은 이 폴더만 사용하면 됩니다.

## 흐름

1. `step0_simple_hash_student.py`
2. `step1_vote_hash_student.py`
3. `step2_vote_chain_student.py`
4. `step3_vote_validation_student.py`

## 실행

```bash
python3 lesson/vote_student/step0_simple_hash_student.py
python3 lesson/vote_student/step1_vote_hash_student.py
python3 lesson/vote_student/step2_vote_chain_student.py
python3 lesson/vote_student/step3_vote_validation_student.py
```

## 수업 서사

- 반장 선거 표를 기록한다
- 기록을 해시로 바꿔본다
- 기록을 서로 연결해본다
- 규칙을 통과한 표만 채택한다

## 특징

- `main()` 없이 위에서 아래로 바로 실행
- 어려운 import 없음
- 공통 모듈 의존 없음
- 학생이 한 파일씩 직접 열어보기 쉬운 구조
