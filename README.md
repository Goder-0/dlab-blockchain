# Python Blockchain Student Kit

이 저장소는 블록체인 특강의 학생 실습용 코드입니다.

## 실습 순서

```bash
python3 lesson/vote_student/step0_simple_hash_student.py
python3 lesson/vote_student/step1_vote_hash_student.py
python3 lesson/vote_student/step2_vote_chain_student.py
python3 lesson/vote_student/step3_vote_validation_student.py
```

## 실습 주제

- 아주 단순한 해시 함수 만들기
- 실제 해시 함수 써보기
- 기록을 연결해보기
- 규칙을 통과한 표만 채택해보기

## MetaMask 지갑 만들기

수업 마지막에는 테스트넷 지갑을 만들고 수료증을 받을 수 있습니다.

학생이 제출할 것은:
- `지갑 주소`

학생이 제출하면 안 되는 것:
- `개인키`
- `시드 문구`
- `비밀번호`

## 주의

지갑 주소만 선생님께 제출하세요.  
개인키와 시드 문구는 누구에게도 보내면 안 됩니다.
